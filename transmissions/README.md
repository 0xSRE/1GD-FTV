# Transmissions Paired with the 1GD-FTV

The 1GD-FTV is mostly sold with an **Aisin AC60 6-speed automatic** or a **Toyota RC-series 6-speed manual**. The Prado 250 is the exception: it uses an **8-speed automatic**. In the codes, **F** means 4WD and **J** means the remote cable-shift manual. 2WD automatics end in **E** (AC60E); 2WD manuals have no suffix (RC61).
