# 1GD-FTV Specifications

## Core specs

| Item | Value | Source |
|---|---|---|
| Layout | Inline 4-cylinder, DOHC, 16 valves | [Spec sheet] |
| Displacement | 2,755 cc | [Spec sheet] |
| Bore × stroke | 92.0 × 103.6 mm | [Spec sheet] |
| Compression ratio | 15.6 : 1 | [Spec sheet] |
| Fuel system | Denso common rail, HP5S supply pump, solenoid injectors | [Spec sheet] |
| Rail pressure | 35–220 MPa (2015 version); up to 250 MPa (2020 update) | [Spec sheet] |
| Turbo | Variable-nozzle (VNT), electric actuator, water-cooled | [Spec sheet] |
| Intercooler | Front-mount air-to-air (water intercooler optional on 2020 update) | [Spec sheet] |
| Cam drive | Two-stage roller timing chain with hydraulic ratchet tensioners | [Spec sheet] |
| Balance shafts | Prado and Hiace from launch; Hilux from the 2020 update | [Spec sheet] |
| Oil pump | Trochoid, gear-driven from crank. Two-stage (variable) pump with oil switching valve on the 2020 update | [Spec sheet] |
| Engine weight | About 270–300 kg with fluids | [Spec sheet] |

## Power and torque

| Variant | Power | Torque |
|---|---|---|
| Original (2015) | 177 PS (130 kW) @ 3,400 rpm | 450 Nm @ 1,600–2,400 rpm (auto). Manual Hilux is rated lower |
| Detuned (some markets) | 151 PS @ 3,600 rpm | 300 Nm @ 1,000–3,400 rpm |
| 2020 update | 204 PS (150 kW) @ 3,400 rpm | 500 Nm @ 1,600–2,800 rpm |
| High-output / GR Sport | 224 PS (165 kW) @ 3,000 rpm | 550 Nm @ 1,600–2,800 rpm |

Ratings vary by market and model, so check the figure for your vehicle.

## Emissions hardware by market

| Standard | Hardware |
|---|---|
| Euro 2 | EGR |
| Euro 4 | EGR + DOC |
| Euro 5 (e.g. Australia, Russia) | EGR + DOC + DPF |
| Euro 6 (e.g. Europe, Japan) | EGR + DOC + DPF + SCR (AdBlue) |

The emissions hardware affects which oil you can use (see [oil-pressure.md](oil-pressure.md)) and how EGT behaves (see [egt.md](egt.md)).
