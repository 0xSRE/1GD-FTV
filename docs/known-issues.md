# Known Issues, DTCs and TSBs

| Issue | DTC(s) | Fix / reference |
|---|---|---|
| DPF clogging, auto-regeneration fails (mostly 2015–2018 vehicles) | P2463 | ECU recalibration plus a manual DPF regeneration button (standard from mid-2018). TSB EG-0026T-0416, EG-00160T-TME |
| Exhaust fuel injector (fifth injector) holes clogged | P2463, P2458 | Replace holder and recalibrate. TSB EG-00350T-TME |
| Dust getting past the air filter, fouling the MAF sensor | — | Check airbox and intake duct seals. Referenced in TSB EG-00119T-TME |
| Glow plug failure | P0671–P0674 | Fit revised plugs, reprogram ECU, check the cylinder for plug-tip fragments. TSB EG-00043T-TME |
| Cam and rocker wear (rough idle) | — | Replace with revised parts. TSB EG-00162T-TME |
| False low oil pressure code (2020-on two-stage pump) | P052477 | ECU reflash changes the detection threshold. TSB EG-00545T-TME |
| Power loss, boost sensor hose comes off | — | Add retaining clip. TSB EG-00588T-TME |
| Injector spray fault (nozzle corrosion or deposits) | P200200 and similar | Replace injectors and program QR correction codes. TSB EG-00605T-TME |
| EGR cooler leak, coolant loss (Land Cruiser GDJ15#) | — | Replace EGR pipe with cooler. TSB EG-00635T-TME |
| EGR valve screws coming loose | — | TSB EG-01004T-TME |
| Unstable cold-start idle | — | TSB EG-00774T-TME |
| Phantom P023A, water in wiring harness | P023A | TSB BE-00566T-TME |
| HP pump-to-rail fuel pipe loose (Prado, Hiace, Mar–Jun 2019) | — | Recall 4571 |
| Particulate matter (PM) sensor faults (2020-on) | P24B1, P24C601, others | Replace sensor and recalibrate |
| NOx sensor fault | P229E12 | Replace sensor and reprogram. TSB EG-00491T-TME |
| AdBlue (urea) pump freezing (Euro 6) | P202D7A | TSB EG-00789T-TME |

Replacement injectors each have a QR correction code that must be programmed into the ECU, or the engine will run poorly and may set injector codes.
