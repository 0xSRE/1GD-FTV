# Toyota 1GD-FTV Reference

Notes on the Toyota **1GD-FTV**, the 2.8 L common-rail turbo-diesel used in the Hilux, Fortuner, Land Cruiser Prado, Hiace and Innova from 2015.

The focus is operating limits an owner can watch on a gauge or OBD scanner: **oil pressure**, **exhaust gas temperature (EGT)** and related values.

## How numbers are labelled

Toyota publishes very little 1GD-FTV service data publicly. Each figure in these docs is tagged with its source:

- **[Factory]**: from Toyota documentation (repair manual, TSB, owner's manual).
- **[Spec sheet]**: from published spec tables (Toyota-Club, Wikipedia and similar).
- **[Community]**: owner or tuner guidance. Use it as a rule of thumb, not as a spec.
- **[Unverified]**: seen in one source only, or the engine it refers to is unclear. Check it before relying on it.

If you have the Toyota repair manual (TIS) values, please update the tables and change the tag to **[Factory]**.
